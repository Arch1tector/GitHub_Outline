# "Тема 1: README синтаксис Markdown"
   То, с чего начинается почти любой репозиторий это файл README, он является и визитной карточкой, и зачастую инструкцией к применению.
Для его оформления нужно знать синтаксис Markdown
Чтобы его изучить и потренироваться нам будет достаточно использовать VSCode и скачать расширение Markdown Prewiew Enhanced, оно, в отдельном окне позволит нам видеть как будет выглядеть 
наш README еще до пуша


И так, первое с чего стоит начать это заголовки, их можно проставить до 6, для этого просто перед словом или фразой достаточн написать #:

## Например:

# Заголовок 
    выглядит как: # Заголовок
## Заголовок
    выглядит как: ## Заголовок
### Заголовок
    выглядит как: ### Заголовок
#### Заголовок
    выглядит как: #### Заголовок
##### Заголовок
    выглядит как: ##### Заголовок
###### Заголовок
    выглядит как: ###### Заголовок

## Для создания списка мы перед текстом просто ставим *, + или -,, нумерацию проставляем вручную:

* текст 1
* текст 2
* текст 3
    * текст
    * текст
    * текст
        - текст
        - текст
        - текст
1. текст
2. текст
3. текст

### Выглядит это примерно вот так:

```

* текст 1
* текст 2
* текст 3
    * текст
    * текст
    * текст
        - текст
        - текст
        - текст
1. текст
2. текст
3. текст

```
*важно не забывать ставить пробел между символом и знаком

## Разграничительные линии ставяться еще проще, при помощи ---, ___ или ***:

---
___
***

### В markdown это выглядит так:

```
---
___
***
```
